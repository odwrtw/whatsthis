# Goal

The goal of this repository is to create a port of the python "guessit" library in golang. The original project is not actively maintained, and a direct Go support would be really great.

I want you to read the original library code, understand how it works (from what I saw, it's basically a huge list of regexes), and port it to Go code.
Try to keep it as simple as possible.
What would be awesome is to port the test suite that's in the repo so we can ensure that our code matches the desired output.
Ask clarifying question if needed.

The code should follow Go idiomatic paradigms, and should be properly linted
